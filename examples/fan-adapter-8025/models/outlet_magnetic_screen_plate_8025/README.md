# outlet_magnetic_screen_plate_8025

Outlet-side magnetic screen adapter plate for an 8025 fan.

The plate screws to the fan using the standard 71.5 mm square fan mounting
pattern. Screws are installed from the screen-facing/service side into the fan.
Each of the four screw locations is a coaxial stepped feature:

- through screw clearance hole
- screen-side screw head recess below the magnet pocket
- larger screen-side pocket for a glued 12 mm x 5 mm magnet

The screw is installed first, then the magnet is glued into the larger pocket.
The center opening keeps the exhaust path clear. Generated artifacts are written
to `outputs/`.
