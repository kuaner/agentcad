# fan_duct_adapter_8025

8025 fan to 80 mm inner-diameter duct adapter.

The model creates a square fan-side flange with four screw holes on the common
71.5 mm 80 mm fan pattern. A round male socket extends from the flange and is
sized at 79.4 mm OD so it can slip into a nominal 80 mm ID duct inlet.

Generated artifacts are written to `outputs/`.
